Bem-vindo ao Projeto Praça Pet

Este projeto foi desenvolvido por Ugo Ventura para o tema TOTVS. Nosso objetivo é unir tecnologia e acessibilidade para que todos possam se divertir e interagir em tempo real.

🎮 Como funciona o jogo?

1. Identificação: Ao entrar, você escolherá um nome. Use o seu nome real para que o grupo te reconheça!

2. O Desenhista: Se o placar mostrar que é a sua vez, você terá ferramentas para desenhar. Você pode usar o mouse ou escolher Desenhos Prontos (Cards) para facilitar.

3. Os Palpites: Se outra pessoa estiver desenhando, observe o quadro e digite seu palpite no chat. Se você acertar, o sistema avisará a todos automaticamente!
